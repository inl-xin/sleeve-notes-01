Entry for the make.fun bounty `u-ravendell-sleeve-notes-for-the-frog-trio-29d80da5`
("Sleeve Notes for the Frog Trio"), by @inl-xin.

An album title and back cover blurb for a jazz trio made entirely of
frogs: "Green in the Evening" — a bullfrog walks the bass line, a tree
frog comps like crickets after dark, and the drummer brushes lily pads
soft as rain.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

Writes `out/entry.txt`, byte-identical on repeat runs. Python 3,
standard library only; no network.
